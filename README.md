# Istante

**Versione corrente: 3.10.4**

Istante è una dashboard/screensaver personale pensata per trasformare uno schermo in un piccolo spazio di calma durante la giornata. Mostra il tempo, propone pensieri e raccolte di frasi, accompagna con radio lo-fi o suoni ambientali, segue luce e meteo, tiene vicino un traguardo e offre timer e calendario senza trasformarsi in una dashboard rumorosa.

L'idea è semplice: **prenditi un momento per te**. Istante può restare aperto su PC, tablet, monitor secondario o display dedicato e fare compagnia dalla mattina alla sera.

## Funzioni principali

- orologio digitale o analogico;
- frasi e raccolte locali, incluse raccolte personali JSON o TXT (una frase per riga);
- radio lo-fi e suoni ambientali offline;
- timer, traguardo e calendario ICS;
- cielo, alba/tramonto, fase lunare, meteo ed effetti discreti;
- condivisione tramite cartolina con QR facoltativo;
- funzionamento offline per le funzioni locali e cache PWA;
- backup/ripristino JSON delle preferenze supportate.
