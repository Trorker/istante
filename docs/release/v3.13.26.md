# Istante 3.13.26

**Data:** 12 settembre 2026  
**Tipo:** manutenzione di produzione / tipografia locale

## Font di produzione

Questa release finalizza la gestione locale dei due caratteri editoriali di Istante.

- **Classic** usa Libre Baskerville Variable 2.005, normale e corsivo.
- **Excalifont** usa Excalifont Regular 1.000.
- `assets/css/fonts.css` non contiene più URL remoti per i font.
- I file originali vengono installati in `assets/fonts/` con `tools/install-fonts.py` oppure con i wrapper PowerShell / shell.
- Dopo l'installazione viene rigenerato `sw.js`, così i font self-hosted entrano nella cache offline verificata.

## Licenze e terze parti

Aggiornato `docs/TERZE-PARTI.md` con versioni, titolari dei diritti e modalità di self-hosting. Aggiunti:

## Distribuzione

Il runtime non dipende da una CDN per Classic o Excalifont. Se i font non sono ancora stati installati, il browser usa i fallback locali dichiarati; per la resa definitiva e l'uso completamente offline vanno installate le copie originali con l'helper incluso prima di pubblicare il sito.
