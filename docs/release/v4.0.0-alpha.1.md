# Istante 4.0.0-alpha.1

Prima release della nuova architettura Vue.

## Obiettivo
Separare definitivamente Istante dalla base 3.x: nessun riuso del vecchio DOM, dei CSS patch o della logica JavaScript legacy.

## Incluso
Dashboard adattiva per quattro famiglie di device, pensieri, radio, timer, calendario ICS, meteo, impostazioni, backup schema 4, IndexedDB, PWA, runtime config e documentazione tecnica.

## Nota calendario telefono
La vista Settimana è deliberatamente nascosta sui telefoni e verrà riprogettata in una release successiva.
