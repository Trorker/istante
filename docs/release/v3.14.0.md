# Istante 3.14.0

**Data:** 12 settembre 2026  
**Tipo:** release di produzione / aggiornamenti e portabilità

## Aggiornamenti più affidabili

La 3.14.0 riscrive la parte più delicata del sistema di aggiornamento.

Nelle release precedenti il service worker considerava obbligatoria una lista molto
ampia di file, compresi documentazione, release storiche e altri contenuti non
necessari all'avvio. Se anche un solo file non era ancora disponibile durante la
pubblicazione, l'installazione poteva diventare `redundant` e l'interfaccia mostrava:

> Nuova copia non completa. Mantengo la versione attuale: puoi riprovare.

Da questa release:

- la **shell essenziale** è separata dai file accessori;
- la versione attuale rimane attiva durante tutta la preparazione;
- i file essenziali vengono verificati prima che il pulsante **Aggiorna** sia disponibile;
- una preparazione incompleta può essere ripresa senza invalidare il nuovo service worker;
- documentazione e file accessori vengono caricati/cachati senza poter bloccare la release;
- `version.json` dichiara lo schema di configurazione e lo schema minimo compatibile.

Se in una release futura lo schema minimo sarà più nuovo di quello della versione in
uso, Istante mostrerà un avviso esplicito e permetterà comunque di scegliere
**Aggiorna comunque**. In quel caso alcune preferenze potrebbero essere riportate ai
valori predefiniti, mentre i dati locali esistenti non vengono cancellati
automaticamente.

## Backup calendario schema 2

Il backup JSON è ora schema 2, mantenendo la lettura dei backup schema 1.

Per i calendari:

- un calendario importato da file ICS continua a essere incluso nel backup;
- un calendario collegato tramite URL salva **URL, nome, stato e colore**, ma non la
  copia ICS scaricata;
- dopo il ripristino su un altro dispositivo, il feed collegato viene risincronizzato
  dall'URL originale quando la rete è disponibile.

Questo evita che un calendario remoto diventi una copia statica dopo il ripristino.

## Collegamenti informativi

I collegamenti informativi principali — **Leggi il progetto**, **Tutte le novità**,
**Questa release**, **Licenza**, **Terze parti** e **Visione e design** — aprono ora
una nuova scheda/pagina. La Dashboard rimane quindi aperta nello stato corrente.

## Pulizia della distribuzione

Lo script Python di manutenzione è stato eliminato e la cartella `tools/` non fa più
parte della release corrente. Il runtime non dipende da Python.

`docs/TERZE-PARTI.md` e le licenze di terze parti restano incluse integralmente nella
distribuzione.
