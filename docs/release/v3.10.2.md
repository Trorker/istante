# Istante v3.10.2

Release di rifinitura dell’interfaccia.

## Modifiche
- calendario senza scroll della pagina;
- compatibilità ICS con `Western/Central Europe`;
- traguardi rapidi in mesi o anni;
- tagline sotto il logo;
- selezione stazioni più pulita;
- eliminazione timer direttamente dalla chip;
- testi secondari più sintetici.
