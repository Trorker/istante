# Istante 4.1.0

Major refactor strutturale basato sulla 3.13.11.

- UI montata da Vue 3 e divisa in componenti.
- Motori esistenti caricati dopo il mount Vue.
- Responsive unico per Phone / Tablet / Computer / Display-TV.
- Scala font separata dal rapporto del viewport.
- CSS runtime ridotto a baseline visuale + responsive engine.
- Calendario mobile con struttura dedicata portrait/landscape.
- Timer desktop/laptop come modale centrata, non fullscreen.
- ICS direct-first con fallback automatico all'API `api.istante.ruslan-dzyuba.it`.
- Service worker aggiornato e senza cache dell'API remota.

## Note di architettura

- `config/runtime.js` espone il proxy ICS remoto e il profilo dispositivo opzionale.
- Un TV Full HD puo essere forzato con `deviceProfile: 'display'`; in automatico la modalita Display viene riservata ai canvas realmente grandi.
- Il service worker non intercetta API o risorse cross-origin e risponde al controllo versione della UI.
