# Istante 3.13.27

**Data:** 12 settembre 2026  
**Tipo:** correzione distribuzione / font vendor

## Font come asset del progetto

Questa release corregge il modello di distribuzione dei caratteri editoriali.
Libre Baskerville ed Excalifont non sono componenti da installare con un comando:
sono normali asset vendor che fanno parte della struttura del sito.

Percorsi runtime:

- `assets/vendor/fonts/libre-baskerville/LibreBaskerville-VariableFont_wght.ttf`;
- `assets/vendor/fonts/libre-baskerville/LibreBaskerville-Italic-VariableFont_wght.ttf`;
- `assets/vendor/fonts/excalifont/Excalifont-Regular.woff2`.

`assets/css/fonts.css` non contiene URL remoti né fallback verso repository esterni.
Gli helper `install-fonts.*` sono stati eliminati.

Il service worker considera questi tre percorsi asset vendor opzionali durante la
creazione della cache: se i file sono presenti nella distribuzione vengono
memorizzati offline automaticamente, senza una fase di installazione separata.
