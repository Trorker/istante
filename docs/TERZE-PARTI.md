# Terze parti

Dipendenze npm: Vue, Vue Router, Pinia, Element Plus, @element-plus/icons-vue, Vite e TypeScript.

Font self-hosted inclusi: Libre Baskerville e Excalifont, con notice nelle rispettive cartelle.

Servizi remoti opzionali: Picsum Photos per lo sfondo fotografico, Open-Meteo per il meteo, stream radio scelti dall'utente/catalogo.

Astronomia solare: equazioni derivate da SunCalc di Vladimir Agafonkin; vedere la nota di licenza nel sorgente `src/services/astronomy.ts`.
