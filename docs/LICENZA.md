## Una distinzione importante

Una licenza che vieta gli usi commerciali **non è una licenza open source
secondo la Open Source Definition dell’OSI**. Per questo Istante viene descritto
come *sorgente disponibile per uso non commerciale*, non come software con
licenza open source approvata dall’OSI.

Questo cambio non restringe retroattivamente i diritti già concessi per le
versioni precedenti distribuite sotto MIT. Le componenti di terze parti
conservano le loro licenze, senza applicare loro nuovi divieti.

l’adeguatezza da un professionista prima della pubblicazione o di accordi con
